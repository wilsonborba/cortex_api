# Cortex Scalar API Documentation / Documentação Scalar / เอกสาร Scalar API

Interactive API documentation for Cortex is hosted directly on the running instance:
* **Interactive Scalar UI:** [`http://localhost:8003/scalar`](http://localhost:8003/scalar) (or `/docs/scalar`)
* **OpenAPI Schema:** [`http://localhost:8003/openapi.json`](http://localhost:8003/openapi.json)
* **Interactive Swagger UI:** [`http://localhost:8003/docs`](http://localhost:8003/docs)
